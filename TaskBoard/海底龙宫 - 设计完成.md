## 🎨 核心功能

### ✨ 同步功能

| 功能 | 命令 | 说明 |
|------|------|------|
| 📊 状态检查 | `-s` | 查看 Git 状态、提交历史、远程差异 |
| 🔍 预览模式 | `-n -p` | 查看将要同步的内容，不执行实际操作 |
| 📝 本地提交 | （无参数） | 仅本地提交，不推送到远程 |
| 🚀 完整同步 | `-p` | 提交并推送到 GitHub |
| 🔄 双向同步 | `-fp` | 拉取 + 提交 + 推送，多设备协作 |
| 📖 详细模式 | `-v` | 显示调试信息和详细日志 |

---

### 🛡️ 安全特性

**三层保护机制：**

1. **预览模式强制审查**
   - 执行前必须确认变更内容
   - 敏感文件无处遁形

2. **自动过滤敏感文件**
   ```
   .openclaw/          # OpenClaw 运行状态
   *.token             # API 令牌
   *.key               # 密钥文件
   *.secret            # 机密文件
   *.env               # 环境变量
   *.log               # 日志文件
   ```

3. **完整日志审计**
   - 每次同步生成独立日志
   - 时间戳 + 级别 + 详细信息
   - 位置：`logs/sync-*.log`

### 方式 2: 命令行（推荐熟练用户）

```bash
cd /path/to/openclaw-sync

# 1. 预览变更
./openclaw-sync.sh -w ~/Desktop/openclaw/Config -n -p

# 2. 执行同步
./openclaw-sync.sh -w ~/Desktop/openclaw/Config -p

# 3. 查看结果
# 访问：https://github.com/LceAn/openclaw-config
```

---

### 方式 3: 环境变量（长期使用）

```bash
# 添加到 ~/.bashrc 或 ~/.zshrc
export OPENCLAW_SYNC_WORKSPACE=~/Desktop/openclaw/Config
export OPENCLAW_SYNC_REPO="LceAn/openclaw-config"

# 重新加载
source ~/.bashrc

# 之后只需
./openclaw-sync.sh -p
```

## 🎯 使用场景

### 场景 1: 每日备份
```bash
# 工作结束前，一键备份
./openclaw-sync.sh -p
```

### 场景 2: 多设备协作
```bash
# 设备 A：推送
./openclaw-sync.sh -p

# 设备 B：拉取 + 推送
./openclaw-sync.sh -fp
```

### 场景 3: 重大变更前
```bash
# 预览变更
./openclaw-sync.sh -n -p

# 确认无误后同步
./openclaw-sync.sh -p
```

### 场景 4: 故障排查
```bash
# 查看详细状态
./openclaw-sync.sh -s -v

# 查看日志
cat logs/sync-*.log | tail -50
```
